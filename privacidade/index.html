Privacidade

Política de privacidade

Como este site trata os dados de quem o visita, nos termos da Lei Geral de Proteção de Dados (Lei 13.709/2018). Atualizada em 9 de novembro de 2026.

Quem é o responsável

Érick Camargo, advogado, OAB/MG nº 224.100, com atuação em Belo Horizonte (MG), é o controlador dos dados tratados neste site.

Que dados são tratados

  • Dados de navegação. Ao acessar qualquer página, o servidor que hospeda o site registra dados técnicos, como endereço IP, tipo de navegador, páginas visitadas, data e hora. Esses registros servem para manter o site funcionando e seguro.
  • Fontes tipográficas. As fontes do site são carregadas do serviço Google Fonts. Para entregá-las, o Google recebe o endereço IP de quem visita a página.
  • Preferência de tema. Se você escolher o modo noturno ou o modo claro, essa escolha fica guardada só no seu navegador, para valer nas próximas visitas. Ela não é enviada a ninguém e pode ser apagada limpando os dados do site no navegador.
  • Estatísticas de visita. O site usa o Cloudflare Web Analytics para contar acessos por página, origem das visitas, país e tipo de aparelho, de forma agregada, para saber quais artigos são mais úteis. Esse serviço não usa cookies, não guarda dados no seu navegador e não identifica quem visita.
  • Vídeos incorporados. Quando um artigo exibir um vídeo do YouTube, o próprio YouTube pode registrar dados e cookies de quem assiste, conforme a política do Google.
  • Mensagens enviadas. Se você entrar em contato, os dados que enviar (nome, forma de contato e o relato) serão usados apenas para responder e, se houver contratação, para a prestação do serviço, sob sigilo profissional.

Para que e com que base

Os dados de navegação e as estatísticas são tratados com base no legítimo interesse de manter o site funcionando, seguro e útil (art. 7º, IX, da LGPD). Os dados de contato são tratados para responder a quem procurou o escritório e, havendo contratação, para executar o contrato (art. 7º, V). Este site não vende dados nem os usa para publicidade.

Com quem são compartilhados

Com os fornecedores necessários para o site existir: a hospedagem (GitHub Pages, do GitHub), as estatísticas de visita (Cloudflare) e o Google, pelas fontes e, quando houver, pelos vídeos. Alguns desses fornecedores processam dados fora do Brasil.

Por quanto tempo

Os registros técnicos ficam pelo prazo que o provedor de hospedagem mantém. Mensagens de contato que não resultem em contratação são apagadas em até 12 meses. Dados de clientes seguem os prazos de guarda da atividade advocatícia.

Seus direitos

Você pode pedir a confirmação de que seus dados são tratados, o acesso, a correção, a anonimização ou a eliminação deles, informações sobre o compartilhamento e a revisão do consentimento, quando for o caso (art. 18 da LGPD). Os pedidos podem ser feitos pelos canais da página Contato. Você também pode reclamar à Autoridade Nacional de Proteção de Dados (ANPD).

Alterações

Esta política pode mudar quando o site ganhar novos recursos. A data no topo indica a versão em vigor.
